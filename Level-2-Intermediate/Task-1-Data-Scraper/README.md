# Data Scraper

## Objective
The objective of this project is to develop a Python web scraper that collects book titles and prices from a website and saves the extracted data into a CSV file.

## Features
- Fetches webpage content using the Requests library
- Parses HTML using BeautifulSoup
- Extracts book titles and prices
- Saves scraped data into a CSV file
- Handles website request errors
## Technologies Used
- Python 3
- Requests
- BeautifulSoup
- CSV

## Website Used
https://books.toscrape.com/
