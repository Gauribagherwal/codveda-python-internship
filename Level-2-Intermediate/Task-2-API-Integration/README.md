# API Integration

## Objective
The objective of this project is to develop a Python program that uses an external weather API to fetch and display weather information.

## Features
- Sends a GET request to an external API
- Fetches current weather information
- Displays temperature
- Displays humidity
- Displays weather code
- Handles API request errors
- Handles invalid API responses
- Handles invalid user input

## Technologies Used
- Python 3
- Requests library
- REST API
- JSON

## API Used
Open-Meteo Weather API
