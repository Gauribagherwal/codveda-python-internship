# Django Task Manager

## Objective
A Django-based Task Manager web application with user authentication, task management, roles and permissions, and password reset functionality.

## Features
- User Registration
- User Login
- User Logout
- Password Reset
- Add Task
- View Tasks
- Edit Task
- Delete Task
- Pending and Completed Task Status
- User-specific Tasks
- Admin Panel
- User Roles and Permissions
- Protected Dashboard

## Technologies Used
- Python 3
- Django 6.1
- SQLite
- HTML
- CSS
