# File Encryption and Decryption

## Objective
The objective of this project is to develop a Python program that can securely encrypt and decrypt files using the Fernet encryption method.

## Features
- Generates an encryption key
- Encrypts files
- Decrypts encrypted files
- Handles missing files
- Handles invalid or corrupted encrypted files
- Protects the secret encryption key from GitHub

## Technologies Used
- Python 3
- Cryptography library
- Fernet encryption
