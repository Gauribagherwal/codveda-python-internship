# N-Queens Problem

## Objective

The objective of this project is to solve the classic N-Queens problem using backtracking.

## Features

- Represents the chessboard using a 2D array
- Uses backtracking to place queens
- Checks safe positions
- Ensures queens are not placed in the same column
- Checks both diagonals
- Displays a valid solution

## Technologies Used

- Python 3

## How to Run

Open the terminal in this folder and run:

```bash
py n_queens.py
