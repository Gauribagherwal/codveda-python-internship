# Word Counter

## Objective
The objective of this project is to develop a Python program that reads a text file and counts the total number of words in the file.

## Features
- Reads text from a file
- Counts the total number of words
- Handles file not found errors
- Simple and user-friendly command-line interface

## Technologies Used
- Python 3

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Navigate to the Task-2-Word-Counter folder.
4. Run the following command:

python word_counter.py

5. Enter the name of the text file when asked.

## Sample File
The project includes a sample text file named `sample.txt`.

## Error Handling
If the entered file does not exist, the program displays:

Error: File not found.
