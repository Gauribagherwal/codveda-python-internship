# Simple Calculator

## Objective
The objective of this project is to develop a simple command-line calculator using Python. The calculator performs four basic arithmetic operations: addition, subtraction, multiplication, and division.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero error handling
- Invalid input handling
- User-friendly menu

## Technologies Used
- Python 3

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Navigate to the Task-1-Calculator folder.
4. Run the following command:

python calculator.py

## Sample Operations
- Addition: 10 + 20 = 30
- Subtraction: 20 - 5 = 15
- Multiplication: 5 × 4 = 20
- Division: 20 ÷ 5 = 4

## Error Handling
The program handles:
- Division by zero
- Invalid numeric input
- Invalid menu selection
